## Modules 内容边界

本层只记录当前事实。跨页面的业务对象、状态、系统协作、数据权威和通用安全规则集中在 `shared/`；页面文件只记录页面目的、边界、当前行为、页面权限、接口使用、兼容契约和未决项。变更原因、实施过程、测试结果和回滚线索统一回到 `changes/YYYY-MM-DD.jsonl`，不在页面文件追加按日期排列的变更章节。

接口事实按接口族整理到 `modules/interfaces/`，数据库表按表整理到 `modules/data/`；页面和业务流程通过链接引用，保持一个权威记录。
