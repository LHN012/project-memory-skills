# Review Report Contract

`model-implement-review` 输出一份中文报告：

- `reports/reviews/<review-name>/review.md`

## 必备章节

- `状态`
- `评审模式`
- `评审范围`
- `输入依据`
- `总体结论`
- `发现列表`
- `回归风险`
- `测试缺口`
- `待确认项`
- `待用户选择`

## 发现列表格式

每条发现建议使用下面结构：

```text
### P1-001 标题

- 位置：文件路径或模块/接口/页面
- 问题：说明具体错误或风险
- 影响：说明会造成什么业务、数据、权限、回归或测试风险
- 建议：说明建议如何处理
- 推荐 skill：model-implement-fix
- 是否需要用户确认：是
- 默认动作：仅记录，不自动修复
```

## 待用户选择

审查完成后必须列出可执行项：

```text
## 待用户选择

- [ ] P1-001：标题，建议交给 model-implement-fix
- [ ] P2-002：标题，建议交给 model-implement
```

规则：

- 可以推荐后续 skill。
- 不允许默认执行后续 skill。
- 必须等待用户明确选择条目后，才允许进入对应 skill。

## 无发现时

如果没有明确发现，写：

- `未发现明确问题`
- 残余风险
- 未覆盖范围
- 已执行或未执行的验证
